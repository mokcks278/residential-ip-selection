## 双 ISP、真实民房托管、普通住宅 IP，到底差在哪

这三个词经常被混着用，实际是三件不同的事。

IP 按注册机构分三类。机房 IP 由云厂商和 IDC 向 ARIN、RIPE、APNIC 申请，WHOIS 里的机构类型写着托管商；住宅 IP 由 Comcast、AT&T、Verizon、Cox 这类宽带运营商分配给家庭用户，机构类型是 ISP 且标注宽带接入；移动 IP 走 4G/5G，运营商用 CGNAT 让大量用户共享同一个地址，信任度最高但可控性最差。

双 ISP 是个技术描述：IP 的 ASN 归属和 WHOIS 里的公司名称都属于 ISP，并且同时接入两家当地运营商。它比单 ISP 住宅 IP 多一些冗余，在风控库眼里仍然是家庭宽带。SixtyNet 的住宅系列默认单 ISP，可以加钱选 Cox Communications 或 Wave Broadband（Wave 已于 2018 年被 Astound 收购）的双 ISP 线路，第三方测评和优惠信息站记录的加价是每月 5 美元。

真实民房托管是另一种形态：硬件真的放在美国住宅里，向当地运营商申请光纤宽带接入。这种 IP 的属性最接近普通住家用户，能过的场景也最硬。

SixtyNet 属于哪一类？官网只写 Residential IP，没有说明是否为民房托管。第三方测评在 2025 年 10 月测过它的 Cox 线路，ipinfo 数据库显示双 ISP 属性，流媒体解锁基本全绿。按这个证据判断，它是双 ISP 住宅 IP 路线，不是民房托管，官网也没有提供民房托管型产品。

这个区别决定用途：

- 做 TikTok、Instagram 多账号，跑 Netflix、Hulu、Disney+，访问 ChatGPT、Claude 这类对机房 IP 限制较多的服务，双 ISP 住宅 IP 够用。
- 要过美国银行风控、Ultra Mobile 免验证登录、CapitalOne 这种金融账户，得找真实民房托管型 VDS，SixtyNet 现有产品线不覆盖这块。

## 下单前先验 IP：四步自查法

买到“假家宽”是这类产品最常见的投诉。IP 属性可以自己查，四步走完基本能判断。

**第一步看 WHOIS 的机构类型。** 用 whois 命令或在线查询，重点看 Organization 和 NetName 字段。住宅 IP 显示为运营商名称，机房 IP 显示为托管商或云厂商。

**第二步看 ASN 归属。** 通过 BGP 查询工具确认 IP 所属自治系统号。住宅 IP 的 ASN 属于宽带运营商，这条是最硬的判据。

**第三步查 IP 类型数据库。** IPinfo、IP2Location、MaxMind 都会标注 usage type，多数有免费查询额度。

**第四步拿目标平台实测。** 注册、登录、看风控提示，这是最终标准，前面三步都只是参考。

第三步有个坑要提前说清楚：**不同数据库的判定互相不一致，同一枚 IP 可能得到四种结论。** SixtyNet 的 Cox 线路在 ipinfo 里被标成双 ISP，但 ipdata 这类库会把同类 IP 标成 business。IPQS 又是另一套逻辑，会对整段甚至整个 ASN 的几百万个地址统一打标，这不是针对你这一枚 IP。Scamalytics 有独立的风险评分体系。别因为某一个库显示 business 就认定 IP 有问题，以你实际要用的平台的反应为准。

另外三条容易漏的检查：PTR 反查，住宅 IP 的反向解析常带运营商域名和地理信息，形如 `xx-xx-xx-xx.hsd1.ca.comcast.net`；黑名单命中数，Spamhaus、Barracuda 这些库最好零命中；地理位置一致性，WHOIS 注册地、GeoIP 归属地、延迟推断位置应该对得上，出现“注册在加州、GeoIP 显示佛州”这种矛盾会被判异常。

用了优惠码的订单，退款后优惠码的使用次数不会恢复。如果码是一次性的，退完就用不了了，这点在下单前想清楚。

部分产品页面单独注明只退网站余额，不原路退回。带 AS9929 的那组住宅 IP 就是这种，跟通用规则并存时以产品页为准。

- **屏蔽 PING。** 官方封锁了 ICMP，测不到延迟属正常，别误判成机器挂了。

## 什么情况下不该买家宽云

家宽资源本身贵，带宽小，流量额度紧。住宅 IP 的上行普遍在 20–200Mbps 之间，机房 IP 常见 100Mbps 到 1Gbps。价格上，机房 IP 月付大致 5–40 美元，住宅 IP 是 40–200 美元，移动 IP 更高。你为这点带宽付的钱，本质是买 IP 在风控库里的身份。

所以两类人不该买：

**需要国内低延迟直连的建站用户。** 用香港 BGP 或 CN2 GIA 线路的普通 VPS，二十几块钱一个月，延迟四十毫秒左右，体验比家宽好得多。

**只想偶尔看剧的人。** 普通机房 VPS 配合流媒体解锁方案，成本低一个数量级。

正确的用法是三层架构：底层用普通美国服务器承担建站、数据库、存储、计算和分发；中层用弹性云服务器做测试和临时任务；最上层只放需要住宅身份的少量关键操作。把整站搬到家宽机器上，是拿最贵的资源干最不需要它的事。

还有一个常被忽略的点：IP 只是风控的一个维度。浏览器指纹、TLS 指纹、鼠标轨迹和打字节奏、系统时区语言货币、DNS 与 WebRTC 出口，任何一环矛盾都会前功尽弃。三处最常见的漏洞是 DNS 泄露（系统 DNS 还指向 8.8.8.8 或国内 DNS）、WebRTC 暴露真实出口、时区语言货币与 IP 所在地不符。多账号场景的原则是一账号一环境：独立浏览器配置文件加独立出口 IP，不共用设备标识、支付信息、收货信息和邮箱域名，也别频繁切换 IP 与环境的组合。
